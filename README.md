# Bang Button

Простой адаптивный сайт с описанием продукта: «Огромная кнопка, огромные деньги».

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

## Файлы

- `index.html` — страница.
- `styles.css` — оформление для компьютеров и телефонов.
- `script.js` — переключение языков и визуальный отклик на нажатие кнопки.

Кнопка работает с мышью, касанием, Enter и пробелом. Системная настройка уменьшения движения отключает анимацию волны. Это демонстрационный интерфейс без платежей и начисления денег.

На большой кнопке размещено описание идеи программы. Каждое нажатие переключает язык по кругу: русский → казахский → английский → русский. Вместе с описанием меняются заголовок страницы и подсказка следующего языка. При открытии страницы выбран русский язык.

## Прототип физической кнопки и сценария LMS

В папке [`demo/`](demo/) находится запускаемая имитация цепочки «нажатие → загрузка домашки → проверка сдачи → сигнал подсветке».

```sh
node demo/run.mjs
```

Нужен Node.js 18+. Подключение к устройству и настоящей LMS пока заменено имитацией. [Настройки, примеры ошибок и схема подключения](demo/README.md).
